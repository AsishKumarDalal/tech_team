# Department 1: Product Manager

The Product Manager agent is responsible for converting ambiguous user ideas into detailed Product Requirement Documents (PRDs).

## Workflow
1. Analyze user input.
2. Determine project complexity (`TINY`, `SMALL`, `MEDIUM`, `LARGE`).
3. Formulate functional requirements (REQ) and features (FEAT).
4. Assign priorities (`P0`, `P1`, `P2`, `P3`).
5. Define explicit acceptance criteria.
