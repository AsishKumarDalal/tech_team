# Department 3: Technical Designers

Technical designers create system, API, and database blueprints before coding starts.

## Agents
1. **System Designer**: High-level module architecture, caching, queues.
2. **Backend Designer**: REST routes, payload validation, status codes.
3. **Database Designer**: ER models, field constraints, Prisma schemas.
4. **Design Critic**: Cross-validates all 3 specs to prevent mismatches.
