# Department 4: Coding

The Coding Department writes the actual software artifacts.

## Sub-Team Roles
- **Code Lead**: Plan, assign files, emit initial project configuration (`package.json`, `tsconfig.json`).
- **Senior Backend Dev**: Core APIs, server logic, database integration.
- **Frontend Dev**: React / Next.js UI components.
- **Junior Dev 1 & 2**: Boilerplate, configuration, and utility functions.
